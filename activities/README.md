# Activities — Build ASP.NET Web Apps with Vibe Coding

Course code: `TGS-2023040477` · Version 6.1

These ten Activities build one cumulative local ASP.NET Core CRM. Each folder is self-contained: it carries its own stage-appropriate `src/LocalCRM` project and fictional `mock-data/` so it can run without copying files from another Activity.

## [Activity 1: Translate Requirements into a Verified ASP.NET Core Scaffold](activity-01-requirements-and-scaffold/README.md)

Turn a LocalCRM customer-contact brief into component boundaries and a reproducible .NET 10 Razor Pages project.
Alignment: LO1 · K1/A1 · 55 minutes

## [Activity 2: Run a Controlled Vibe-Coding Change](activity-02-controlled-vibe-change/README.md)

Add a health endpoint through a specify–generate–inspect–verify loop without accepting unrelated AI edits.
Alignment: LO1 · K1/A1 · 45 minutes

## [Activity 3: Build an Accessible Razor Pages Shell](activity-03-accessible-razor-shell/README.md)

Create semantic navigation, visible keyboard focus and a labelled customer-contact entry point.
Alignment: LO2 · K2/A2 · 55 minutes

## [Activity 4: Audit Accessibility with axe and Manual Evidence](activity-04-accessibility-audit/README.md)

Create a repeatable automated-plus-manual accessibility gate for the running Razor Pages UI.
Alignment: LO2 · K2/A2 · 45 minutes

## [Activity 5: Create and List CRM Contacts with Razor Pages](activity-05-razor-create-list/README.md)

Implement page-focused create/list handlers through an injectable contact store.
Alignment: LO3 · K3/A3 · 65 minutes

## [Activity 6: Enforce Validation and Antiforgery Controls](activity-06-validation-and-antiforgery/README.md)

Reject invalid or forged commands while returning accessible recovery guidance.
Alignment: LO3 · K3/A3 · 50 minutes

## [Activity 7: Expose a Controller-Based CRUD API](activity-07-controller-api/README.md)

Add a JSON controller surface that reuses the application service without exposing persistence entities.
Alignment: LO4 · K4/A4 · 65 minutes

## [Activity 8: Prove Persistence and Interoperability](activity-08-sqlite-openapi-tests/README.md)

Replace volatile state with EF Core SQLite, publish an OpenAPI contract and verify components through integration tests.
Alignment: LO4 · K4/A4 · 70 minutes

## [Activity 9: Prepare an Azure-Ready Release](activity-09-production-readiness/README.md)

Create a production-neutral publish artifact with validated configuration, health endpoints and smoke evidence.
Alignment: LO5 · K5/A5 · 60 minutes

## [Activity 10: Produce the Traceable Design and Release Record](activity-10-design-documentation/README.md)

Map user specifications to components, interface contracts, decisions and verification evidence.
Alignment: LO5 · K5/A5 · 55 minutes
